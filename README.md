# Rent·Control

Telegram Mini App для обліку оренди, роботи, цілей і активів. Усі дані — у твоїх базах Notion.

## Що всередині (v5)

- **Пульс** — заробіток місяця з графіком за пів року (пальцем можна «прогорнути» місяці), прогноз за темпом, найближчі оплати, звіт за день / тиждень / місяць / рік (доходи й витрати по категоріях), тренд за рік, капітал.
- **Оренда** — живий лічильник доходу, статуси оплат, пошук і фільтри, картка орендаря зі шкалою оплаченого періоду, нагадування в Telegram з готовим текстом, реферальні бонуси, аналітика «виконано / наперед».
- **Робота** — календар-теплокарта годин, категорії зі ставками, підробітки, виплати (аванс / фактична, загальні чи по категорії), архів місяців.
- **Капітал** — цілі з рівнями й прогнозом, крипто-портфель з графіком, середньою ціною й P&L.
- Швидке додавання з центральної кнопки, «Скасувати» після видалення, робота з кешу, якщо Notion недоступний, світла й темна теми (за Telegram).

## Збірка

```bash
npm install
npm run build   # → dist/ — це й публікує Vercel
npm run demo    # → dist-demo/index.html — офлайн-демо з фейковим Notion і демо-даними
```

Параметри демо: `?theme=light`, `?empty=1` (без даних), `?lat=600` (затримка «Notion», мс).

## Структура

```
src/lib/        дати, гроші й курси, доменна логіка (rent, work, overview, capital), Notion (schema, api)
src/state/      сховище, стан інтерфейсу, дії (оптимістичні записи, відкати, синхронізація)
src/screens/    Пульс, Оренда, Робота, Капітал
src/sheets/     нижні вікна: форми, картки, підтвердження, налаштування
src/ui/         дизайн-система: іконки, графіки, компоненти, вікна
dev/            фейковий Notion (сувора перевірка колонок), демо-дані, вхід демо-збірки
api/            функції Vercel: проксі до Notion (білий список баз) і CoinGecko
```

## Змінні у Vercel (без змін)

```
NOTION_TOKEN
DB_CLIENTS  DB_PAYMENTS  DB_WORK_ENTRIES  DB_WORK_CATEGORIES  DB_PAYOUTS
DB_EXPENSES  DB_CAT_EXPENSES      — з Expense·Control (витрати у звітах)
DB_GOALS  DB_GOAL_TX              — модуль «Цілі» (необовʼязково)
DB_ASSETS  DB_ASSET_TX            — модуль «Активи» (необовʼязково)
```

`DB_INCOMES`, `DB_CAT_INCOMES`, `DB_REGULARS` застосунок не використовує.

## Сумісність з Notion

Назви й типи колонок, формати значень — ті самі, що у v3: нова версія читає й пише ті самі бази без змін.
